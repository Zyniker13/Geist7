# Geist7

Twenty-five original, iPad-first strategy games (Set Two) for iOS, iPadOS, and macOS, each a self-contained Swift app in its own folder.

- `games/` holds the games: [`games/README.md`](games/README.md) is the index, and each `games/NN-<slug>/ROADMAP.md` specifies one game, with its `RESEARCH.md`.
- `games/_shared/` holds the conventions, the Set Two addendum, and the template every game follows.
- `ROADMAP.md` is how the program runs: build order, repository layout, maintainer issues, and moving from one game to the next.
- `STATUS.md` is where the program stands right now.

Each game is premium (one universal purchase), plays offline, uses no custom servers, and targets an App Store privacy label of Data Not Collected.
