# Rosette — Age Rating Questionnaire Draft

The maintainer answers the questionnaire in App Store Connect (issue #11);
these are the accurate answers to copy. Rosette has no real-money wagering,
no purchasable currency, and no cash-out: the purse and stakes are in-game
only.

| Question | Answer |
| --- | --- |
| Cartoon or fantasy violence | None |
| Realistic violence | None |
| Prolonged graphic violence | None |
| Profanity or crude humor | None |
| Mature/suggestive themes | None |
| Horror/fear themes | None |
| Medical/treatment information | None |
| Alcohol, tobacco, or drugs | None (tavern setting is cosmetic) |
| Simulated gambling (games of chance with wagering that uses only in-game currency) | **Yes** — dice are the core loop; the stake, doubling cube, and purse use in-game currency only |
| Contests/sweepstakes with real prizes | No |
| Gambling with real money (or cash-out of in-game currency) | **No** — no purchase converts to currency, no currency converts to cash, no prizes |
| Unmoderated user-generated content | No |
| Chat with strangers | No (no free-text chat in 1.0) |
| Web links to external content | None that bypass parental controls |
| Age-of-empire/historical violence | None |

**Resulting age rating:** **12+** under Apple's rubric for simulated
gambling (frequent simulated gambling raises the floor; Ur's dice are
continuous gameplay). Also answer the Game Center check (on: leaderboards
via Game Center, if enabled at submission).

**Cross-check:** the doubling cube and omen tokens are wager mechanics on an
in-game purse; no form of them is redeemable, purchasable, or transferable.
This matches the roadmap's online/privacy choices (telemetry-free,
no accounts for the core game).
